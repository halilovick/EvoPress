\begin{frame}{What changed since the last meeting?}
\begin{itemize}
    \item The main evidence moved from TinyLlama feasibility to \textbf{Mistral-7B experiments}.
    \item I implemented and tested a joint search pipeline for \textbf{depth pruning + quantization}.
    \item I compared:
    \begin{itemize}
        \item depth-only pruning,
        \item quantization-only search,
        \item independent depth + quantization,
        \item joint depth + quantization search.
    \end{itemize}
    \item I evaluated the main results on WikiText2, C4, FineWeb-Edu, and LM-eval tasks.
    \item The result is promising, but not a simple ``joint search always wins'' story.
\end{itemize}

\vspace{0.2cm}
\begin{block}{Current high-level finding}
Joint search improves perplexity over matched independent compression, but the benefit depends on quantization scope and evaluation metric.
\end{block}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}{Refined research question}
\begin{block}{Thesis question}
Can EvoPress-style evolutionary search optimize \textbf{depth pruning} and \textbf{weight quantization} jointly, and when is this better than applying both methods independently?
\end{block}

\vspace{0.25cm}
\textbf{Why this is interesting}
\begin{itemize}
    \item Pruning removes complete attention or MLP modules.
    \item Quantization changes the weights of selected projection modules.
    \item These two decisions can interact.
    \item A pruning mask that works well alone may not be the best mask after quantization.
\end{itemize}

\vspace{0.2cm}
\begin{block}{More precise framing}
The thesis is about the \textbf{quality-compression tradeoff} of joint multi-method compression, not about proving that joint search is always superior.
\end{block}
\end{frame}

\begin{frame}{Independent vs. joint search}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\begin{block}{Independent compression}
\begin{center}
\texttt{depth search}\\
$\downarrow$\\
\texttt{quant search}\\
$\downarrow$\\
\texttt{combine configs}\\
$\downarrow$\\
\texttt{evaluate final model}
\end{center}
\end{block}

\textbf{Problem:} each method is optimized mostly as if the other method did not exist.
\end{column}

\begin{column}{0.48\textwidth}
\begin{block}{Joint compression}
\begin{center}
\texttt{candidate = depth mask + quant assignment}\\
$\downarrow$\\
\texttt{mutate candidate}\\
$\downarrow$\\
\texttt{evaluate combined model}\\
$\downarrow$\\
\texttt{select next parent}
\end{center}
\end{block}

\textbf{Goal:} select configurations that work well after both compression methods are active.
\end{column}
\end{columns}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}{What is one joint-search candidate?}
\begin{block}{One candidate represents one compressed model}
A joint-search candidate contains both compression decisions at the same time.
\end{block}

\vspace{0.2cm}
\textbf{Part 1: depth mask}
\begin{itemize}
    \item For each transformer block, decide whether attention is kept or dropped.
    \item For each transformer block, decide whether the MLP is kept or dropped.
\end{itemize}

\vspace{0.15cm}
\textbf{Part 2: quantization assignment}
\begin{itemize}
    \item For selected projection modules, assign a bitwidth such as 2, 3, or 4 bits.
    \item The assignment must satisfy the target average bitwidth budget.
\end{itemize}

\vspace{0.15cm}
\begin{block}{Key point}
The candidate is not evaluated as pruning alone or quantization alone. It is evaluated as one final depth-pruned and quantized model.
\end{block}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}{One generation of joint search}
\begin{enumerate}
    \item Start from the current parent candidate.
    \item Copy it to create offspring candidates.
    \item Mutate each offspring.
    \begin{itemize}
        \item In the main runs, each offspring mutates either the depth mask or the quantization assignment.
        \item The choice is random (50/50).
        \item If the depth mask changes, the active quantization budget is repaired so the average bitwidth stays valid.
        \item New interaction-aware mode: mutate depth, repair active quant budget, then adjust quantization on touched active layers.
    \end{itemize}
    \item Assemble the compressed candidate.
    \item Evaluate fitness using KL divergence against the dense model.
    \item Keep the best candidate as the next parent.
\end{enumerate}
\end{frame}

\vspace{0.25cm}
\textbf{Interpretation}
\begin{itemize}
    \item The strongest evidence is on perplexity.
    \item \texttt{q\_proj} joint search is the best current quality-compression point.
    \item Attention-scope joint search gives higher compression, but lower quality.
    \item LM-eval is more mixed, so I should not overclaim downstream improvement.
\end{itemize}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}{What the results support}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\begin{block}{Supported}
\begin{itemize}
    \item Joint search is executable on Mistral-7B.
    \item Joint search improves matched independent compression in PPL.
    \item The effect appears on WikiText2, C4, and FineWeb-Edu.
    \item Quantization scope strongly changes the tradeoff.
\end{itemize}
\end{block}
\end{column}

\begin{column}{0.48\textwidth}
\begin{block}{Not supported}
\begin{itemize}
    \item Not evidence that joint search always wins.
    \item Not yet evidence for full all-linear Mistral compression.
    \item Not a clear downstream task improvement for every setting.
    \item Not yet evidence that the new interaction-aware mutation improves results; it still needs matched experiments.
\end{itemize}
\end{block}
\end{column}
\end{columns}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}{How this shapes the thesis}
\begin{block}{Careful thesis claim}
Joint EvoPress-style depth+quantization search improves matched independent compression in perplexity, but the benefit depends on quantization scope and evaluation metric.
\end{block}

\vspace{0.25cm}
\textbf{Thesis direction}
\begin{itemize}
    \item Extend EvoPress from single-method compression to joint multi-method compression.
    \item Study how pruning masks and quantization assignments interact.
    \item Compare independent and joint optimization under matched compression.
    \item Explain the compression-quality tradeoff rather than only reporting best numbers.
\end{itemize}

\vspace{0.2cm}
\begin{block}{Open question for the thesis}
Can the new interaction-aware mutation become the concrete algorithmic contribution beyond simply combining two existing compression methods?
\end{block}
\end{frame}

\begin{frame}{Backup: depth pruning and simple baselines}
\begin{itemize}
    \item Mistral depth pruning was first validated independently.
    \item Random and late-layer dropping were added as cheap baselines.
    \item These simple baselines often produced much worse or collapsed PPL.
    \item This supports that module choice matters, not only the number of dropped modules.
\end{itemize}

\vspace{0.25cm}
\begin{block}{Why this matters}
The joint experiments build on a meaningful depth-pruning search, not on arbitrary layer removal.
\end{block}
\end{frame}
